## 🔗 Links

## 📌 What is SplitSense?

SplitSense is an **AI-powered conversion optimization platform**.

It analyzes website behavior to identify potential problems affecting:

* Conversions
* Signups
* Checkout
* Forms
* User journeys
* Messaging
* Page performance

It can then help create and run experiments to test improvements. ([splitsense.ai](https://splitsense.ai/))
