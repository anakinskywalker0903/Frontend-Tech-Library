# Taste Skill

> An open-source frontend design framework for AI coding agents focused on avoiding generic visual patterns and producing more intentional interfaces.

## 🔗 Links

* **Website:** https://www.tasteskill.dev/
* **Documentation:** https://www.tasteskill.dev/docs
* **GitHub:** https://github.com/Leonxlnx/taste-skill

## 📌 What is Taste Skill?

Taste Skill provides rules and workflows that guide AI coding agents toward more deliberate frontend design.

Its goal is to reduce predictable AI-generated aesthetics and encourage the agent to establish a stronger visual direction before implementing the interface.

## ✨ Key Ideas

Taste Skill focuses on:

* Typography
* Spacing
* Colors
* Layout
* Visual direction
* Responsive design
* Motion
* Design-system consistency
* Redesign workflows

## 🎨 Design Direction

The current v2 workflow can infer a design direction from the brief, including:

* Industry
* Audience
* Mood
* Motion depth
* Layout style

It can also map a project to established design systems such as Material, Fluent, Carbon, Polaris, Atlassian, Primer, shadcn, and others when appropriate.
