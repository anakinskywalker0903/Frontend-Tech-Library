## 📌 What is Anti UI Slop?

Anti UI Slop is a skill for AI coding agents designed to prevent them from producing generic, template-like interfaces.

Instead of allowing an agent to invent another predictable SaaS interface, it encourages the agent to work from:

* The actual product
* Existing components
* Design tokens
* Existing visual language
* Real UI references
* Required interface states

UIZZE's workflow can use a library of real web and iOS screens as visual references.

## 🤖 What It Does

The skill helps agents:

* Build product-specific interfaces
* Avoid generic AI-generated UI patterns
* Reuse existing design systems
* Consider loading, empty, error, success, disabled, and permission states
* Review interfaces before shipping
* Run a final UI quality gate
