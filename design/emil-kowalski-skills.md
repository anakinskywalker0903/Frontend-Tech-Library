## 📌 What is it?

Emil Kowalski's skills provide AI coding agents with practical guidance for building interfaces that feel polished rather than simply functional.

The skills focus heavily on the **craft layer** of frontend development:

* Animation
* Easing
* Interaction
* Components
* Micro-interactions
* Visual refinement
* User experience

## ✨ What It Helps With

The skills can guide an AI agent when working on:

* UI animations
* Component interactions
* Transitions
* Hover effects
* Enter/exit animations
* Motion timing
* Easing
* Micro-interactions
* Animation reviews

## 🎬 Animation Focus

A major focus is making animations feel intentional.

Instead of:

```text
Element appears
      ↓
Basic animation
```

The goal is:

```text
User Action
     ↓
Interaction
     ↓
Motion + Easing
     ↓
Feedback
     ↓
Polished Experience
```

This is particularly useful when an AI-generated interface technically works but still feels "vibe-coded."

## 🧩 Design Engineering

The skills bridge the gap between:

```text
Design
   +
Frontend Development
   +
Animation
   ↓
Design Engineering
```

This makes the collection useful for developers who want to improve the details of an existing interface rather than completely redesign it.
