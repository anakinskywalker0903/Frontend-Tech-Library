# Vercel Web Design Guidelines

> A collection of web interface guidelines for building accessible, responsive, consistent, and polished web experiences.

## 🔗 Links

* **Guidelines:** https://vercel.com/design/guidelines
* **GitHub:** https://github.com/vercel-labs/web-interface-guidelines
* **Agent Skills:** https://skills.sh/vercel-labs/agent-skills

## 📌 What is it?

Vercel's Web Design Guidelines provide practical rules for reviewing and improving web interfaces.

They cover details that are easy to miss when building a UI, especially when an interface is generated or heavily assisted by AI.

## ✨ What It Covers

The guidelines cover areas such as:

* Accessibility
* Responsive behavior
* Forms
* Focus states
* Interaction
* Navigation
* Typography
* Content structure
* Performance
* UX
* Loading states
* Error states
* Mobile behavior

## 🔍 UI Auditing

The guidelines are particularly useful as a **final UI review checklist**.

```text
Build UI
   ↓
Functional
   ↓
Web Design Guidelines
   ↓
Audit
   ↓
Fix Edge Cases
   ↓
Ship
```

Instead of only asking:

> "Does the page work?"

you can evaluate:

> "Does the page handle the details a real production interface needs?"

## ♿ Accessibility

The guidelines encourage developers to consider things such as:

* Keyboard navigation
* Focus states
* Semantic HTML
* Accessible controls
* Appropriate labels
* Contrast
* Reduced-motion preferences

## 📱 Responsive Design

A UI should not only look good at one desktop resolution.

Consider:

```text
Desktop
   ↓
Tablet
   ↓
Mobile
   ↓
Small screens
```

Responsive behavior should be intentional rather than simply relying on elements shrinking.

## 📝 Forms

Forms should account for real user behavior, including:

* Labels
* Validation
* Error messages
* Loading states
* Disabled states
* Keyboard interaction
* Appropriate input types

## 🎯 Best Used For

* Final UI audits
* AI-generated frontend
* Production websites
* React / Next.js applications
* Accessibility reviews
* Responsive design reviews
* UX refinement

## 🧠 Key Idea

The guidelines help catch the details that are often missing from an otherwise functional interface.

```text
Functional UI
      +
Accessibility
      +
Responsive Design
      +
Interaction States
      +
Edge Cases
      ↓
Production-Ready UI
```
