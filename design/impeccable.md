# Impeccable

> A design skill for AI coding agents that provides a shared vocabulary for creating, reviewing, and refining frontend interfaces.

## 🔗 Links

* **Website:** https://impeccable.style/
* **GitHub:** https://github.com/adawdani/impeccable--Design-for-Agents

## 📌 What is Impeccable?

Impeccable gives AI coding agents a **design vocabulary** for making interfaces more intentional.

It can help an agent move beyond simply making a page functional and focus on:

* Typography
* Layout
* Color
* Spacing
* Motion
* Interaction
* Responsive behavior
* Design systems
* Visual refinement

It also includes deterministic checks for common AI-generated design patterns.

## 🛠️ Design Commands

Examples include:

```text
create
audit
critique
typeset
layout
colorize
animate
polish
simplify
distill
clarify
adapt
harden
```

These commands give the agent more precise instructions than simply asking it to "make the UI better."

## 📄 Design System Support

Impeccable can generate and maintain files such as:

```text
PRODUCT.md
DESIGN.md
```

These can capture information about:

* Users
* Product purpose
* Brand direction
* Colors
* Typography
* Components
* Design decisions

This allows future AI work to stay consistent with the existing design system.
