## 📌 What is Cue?

Cue is a curated collection of **Awwwards-style UI components** for developers and designers.

It focuses on interfaces that go beyond basic component libraries, with emphasis on:

* Hero sections
* Interactions
* Page transitions
* Scroll animations
* 3D / WebGL
* Cursor effects
* Buttons
* Forms
* Micro-interactions

Each component also includes an **AI prompt** designed for tools such as Cursor, v0, Bolt, Claude, and other coding assistants. ([cuedesign.space](https://cuedesign.space/?utm_source=chatgpt.com))
