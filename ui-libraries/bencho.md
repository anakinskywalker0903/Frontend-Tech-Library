# Bencho

> An interactive collection of frontend UI blocks that can be explored, customized, and copied into projects.

## 🔗 Links

* **Website:** https://bencho.dev/

## 📌 What is Bencho?

Bencho is a collection of interactive **frontend UI blocks**.

Instead of simply browsing static screenshots, you can interact with the blocks directly and inspect/copy their implementation.

The blocks are **MIT licensed**, allowing them to be used, modified, and shipped commercially under the license terms. ([bencho.dev](https://bencho.dev/licence?utm_source=chatgpt.com))

## ✨ Key Features

* Interactive UI blocks
* Live previews

* MIT-licensed blocks
