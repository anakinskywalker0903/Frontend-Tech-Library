## 📌 What is Ant Design?

Ant Design, also known as **AntD**, is a React UI component library developed by Ant Group.

It provides a large collection of ready-to-use components and follows a design system focused on building professional and data-heavy web applications.

## ✨ Key Features

* Large component library
* React support
* TypeScript support
* Accessible components
* Form handling
* Data tables
* Data visualization components
* Customizable themes
* Internationalization
* Design system

## ⚠️ Keep in Mind

Ant Design provides a **large, opinionated design system**. This makes it excellent for quickly building consistent applications, but it may require more customization if you're trying to create a highly unique visual design.

It is also a different approach from libraries such as **shadcn/ui**, where you typically own and customize the component source code directly.
