# Evil Buttons

> A collection of highly animated, playful button components built with shadcn/ui, Motion, and Tailwind CSS.

## 🔗 Links

* **Website:** https://www.evilbuttons.com/

## 📌 What is Evil Buttons?

Evil Buttons is a collection of **animated React button components** designed to add personality and interaction to interfaces.

The components use:

* React
* Tailwind CSS
* Motion
* shadcn/ui registry

The components are copy-paste friendly and can be installed using the shadcn CLI. ([evilbuttons.com](https://www.evilbuttons.com/))

## ✨ Key Features

* Animated buttons
* Interactive states
* Motion effects
* Glitch effects
* Hover interactions
* Hold interactions
* Playful visual styles
* shadcn registry integration

## ⚙️ Installation

Example:

```bash
npx shadcn@latest add @evilbuttons/frame-button
```

The component source is then available directly inside your project. ([evilbuttons.com](https://www.evilbuttons.com/docs/minimal-button))

## 🎯 Best Used For

* Developer portfolios
* Creative websites
* Landing pages
* Hackathon projects
* Interactive CTAs
* Experimental UI

## 🧠 Key Idea

Evil Buttons focuses on making **small UI elements feel alive** through animation and interaction.

```text
Button
  +
Motion
  +
Interaction
  ↓
Expressive UI
```

## ⚠️ Keep in Mind

The highly playful visual style isn't appropriate for every product. For serious or highly utilitarian interfaces, simpler button systems may be more suitable.
