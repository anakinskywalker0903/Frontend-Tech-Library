# DaisyUI

> A Tailwind CSS component library that provides ready-to-use UI components without requiring custom CSS for every component.

## 🔗 Links

* **Website:** https://daisyui.com/
* **Documentation:** https://daisyui.com/docs/
* **GitHub:** https://github.com/saadeghi/daisyui

## 📌 What is DaisyUI?

DaisyUI is a component library and Tailwind CSS plugin that provides semantic class names for common UI components.

It extends Tailwind CSS with pre-designed components while still allowing you to use Tailwind utilities for customization.

## ✨ Key Features

* Tailwind CSS based
* Semantic component classes
* Multiple themes
* Dark mode support
* Responsive components
* Lightweight
* Framework agnostic
* No JavaScript required for many components

## ⚙️ Installation

For a Tailwind CSS project:

```bash id="v7p3qm"
npm install daisyui
```

Then add DaisyUI to your Tailwind setup according to the current installation guide.

## 🧪 Basic Example

```html id="n5k8rx"
<button class="btn btn-primary">
  Click Me
</button>
```

Instead of manually building the button's styling, DaisyUI provides the semantic `btn` component class.

## 🎨 Themes

One of DaisyUI's major features is its built-in theme system.

You can switch between themes without having to manually redefine every component's colors.

```html id="q2m6wt"
<html data-theme="dark">
```

DaisyUI provides many built-in themes and also allows you to create custom themes.

## ⚠️ Keep in Mind

DaisyUI is built around **Tailwind CSS**, so it makes the most sense when Tailwind is already part of your project.

Compared with shadcn/ui, DaisyUI generally provides components through CSS classes rather than giving you component source code to own and modify directly.
