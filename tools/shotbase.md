# Shotbase

> A macOS capture and editing workspace for screenshots, screen recordings, webpage captures, annotations, and sharing.

## 🔗 Links

* **Website:** https://shotbase.com/

## 📌 What is Shotbase?

Shotbase is a desktop application for **capturing, editing, organizing, and sharing visual content**.

It combines several workflows into one tool:

```text
Capture
  ↓
Edit
  ↓
Annotate
  ↓
Organize
  ↓
Share
```

## ✨ Key Features

* Screenshots
* Screen recording
* Full-page webpage capture
* Scrolling screenshots
* Annotations
* Text
* Arrows
* Highlights
* Backgrounds
* Frames
* Shadows
* 3D transforms
* Automatic zooms
* AI summaries
* Automatic tagging
* Local AI
* Sharing links

## 🤖 Local AI

Shotbase uses AI locally on compatible Macs to help:

* Name captures
* Tag captures
* Summarize visual content
* Search your capture library

The company states that visual content is not sent to a remote model for this processing. ([shotbase.com](https://shotbase.com/))

## 🎯 Best Used For

## 🧠 Key Idea

Shotbase combines **screen capture + editing + organization + sharing** into one workflow.

## ⚠️ Keep in Mind

Shotbase is currently a **macOS application** and its local AI features require Apple silicon Macs. ([shotbase.com](https://shotbase.com/))
