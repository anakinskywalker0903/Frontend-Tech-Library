# With Animation

> A library of interactive SwiftUI animations and components that can be explored, customized, and tuned directly in the browser.

## 🔗 Links

* **Website:** https://withanimation.app

## 📌 What is With Animation?

With Animation is a growing collection of **SwiftUI animations and interactive components**.

Instead of simply watching an animation preview, you can interact with components in the browser and adjust parameters such as:

* Speed
* Colors
* Size
* Spring values
* Intensity
* Interaction behavior

You can then use the resulting animation as a reference or download the corresponding SwiftUI code.

## ✨ What You'll Find

The library includes experiments and components involving:

* Loaders
* Gestures
* Transitions
* Shaders
* 3D interactions
* Interactive controls
* Spring animations
* Custom UI experiments

## 🎛️ Interactive Tuning

One of the main ideas is experimenting with animation parameters in real time.

```text
Component
    ↓
Adjust Parameters
    ↓
Preview Animation
    ↓
Tune Motion
    ↓
Use / Download Code
```

This makes it useful for learning how small changes in spring, timing, size, or intensity affect the feel of an interaction.

## 🧠 Key Idea

With Animation is more than an animation gallery.

It provides an **interactive playground** where you can experiment with the parameters behind an animation instead of only looking at the final result.
