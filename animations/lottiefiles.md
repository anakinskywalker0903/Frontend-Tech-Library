# LottieFiles

> A platform for discovering, creating, and integrating lightweight Lottie animations into websites and applications.

## 🔗 Links

* **Website:** https://lottiefiles.com/
* **Documentation:** https://developers.lottiefiles.com/
* **GitHub:** https://github.com/LottieFiles

## 📌 What is LottieFiles?

LottieFiles is a platform and ecosystem built around **Lottie animations**.

It provides a large collection of ready-made animations, along with tools for creating, editing, previewing, and integrating animations into websites and applications.

Lottie animations are typically vector-based and can be rendered efficiently across different platforms.

## ✨ Key Features

* Large animation library
* Ready-to-use animations
* Lottie animation editor
* Web integration
* React support
* Interactive animations
* Lightweight vector animations
* Animation customization

## 🧠 What is Lottie?

Lottie is an animation format that represents animations as structured data, commonly exported from tools such as Adobe After Effects using the Bodymovin workflow.

Instead of using a video or GIF, a Lottie animation can be rendered dynamically.

```text id="q6n4xs"
Animation Design
      ↓
Lottie / JSON
      ↓
Lottie Runtime
      ↓
Browser
      ↓
Animated UI
```

## ⚙️ Web Integration

LottieFiles provides web libraries and components for displaying Lottie animations.

For example, the Lottie Web player can be added to a project through npm:

```bash id="f5k8rm"
npm install @lottiefiles/dotlottie-web
```

## 🎯 Best Used For

* Loading animations
* Empty states
* Animated illustrations
* Landing pages
* Onboarding experiences
* Micro-interactions
* Icons and UI animations
* Marketing websites

## ⚠️ Keep in Mind

Lottie is generally better suited for **pre-designed animations and illustrations** than complex real-time interactive graphics.

For highly interactive animations controlled by application state, tools such as Rive can be a better fit.
