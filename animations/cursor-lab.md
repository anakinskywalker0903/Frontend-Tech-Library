# Cursor Lab

> An interactive collection of customizable cursor effects for modern websites.

## 🔗 Links

* **Website:** https://cursor-lab-ui.vercel.app/

## 📌 What is Cursor Lab?

Cursor Lab is a collection of **custom cursor designs and interactions** that can be configured visually and then copied into a project.

It provides multiple cursor styles with controls for experimenting with their appearance and behavior. ([craftworkdesign](https://www6.twstalker.com/craftworkdesign))

## ✨ Key Features

* Custom cursor effects
* Interactive previews
* Cursor customization
* Multiple cursor styles
* JavaScript output
* React output
* CSS output
