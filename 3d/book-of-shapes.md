# Book of Shapes

> A curated gallery of generative SVG patterns that can be customized and downloaded for web and design projects.

## 🔗 Links

* **Website:** https://bookofshapes.com/

## 📌 What is Book of Shapes?

Book of Shapes is a collection of **generative patterns and SVG artwork**.

It allows you to explore algorithmically generated visual patterns and use them as design assets.

The collection contains patterns across multiple categories and is designed around customization and downloading. ([hyperhabitat.de](https://hyperhabitat.de/))

## ✨ Key Features

* Generative patterns
* SVG assets
* Customizable designs
* Multiple pattern categories
* Downloadable artwork
* Open-ended visual experimentation
