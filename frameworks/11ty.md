# Eleventy (11ty)

> A simpler static site generator for building fast websites with JavaScript, HTML, and multiple templating languages.

## 🔗 Links

* **Website:** https://www.11ty.dev/
* **Documentation:** https://www.11ty.dev/docs/
* **GitHub:** https://github.com/11ty/eleventy

## 📌 What is Eleventy?

Eleventy, commonly called **11ty**, is a static site generator that transforms templates and content into HTML files.

Unlike many modern frontend frameworks, Eleventy doesn't require a client-side JavaScript framework to build a website.

It focuses on producing **simple, fast, and lightweight websites**.

## ✨ Key Features

* Static site generation
* Zero client-side JavaScript by default
* Supports multiple template languages
* Markdown support
* Data-driven pages
* Fast builds
* Highly customizable
* Framework-agnostic

```bash id="y6p4kw"

```

Run Eleventy:

```bash id="5g1r3x"
npx @11ty/eleventy
```

Start development mode:

```bash id="j7v4qa"
npx @11ty/eleventy --serve
```

## 🧪 Example

A Markdown file:

```markdown id="v3x9rm"
# Hello World

This page was generated with Eleventy.
```

Eleventy can process this content and generate a static HTML page.

## 🧩 Supported Template Languages

Eleventy supports several templating languages, including:

* HTML
* Markdown
* Nunjucks
* Liquid
* Handlebars
* JavaScript
* WebC
* and more

## 🎯 Best Used For

* Blogs
* Documentation websites
* Personal websites
* Portfolios
* Marketing websites
* Content-focused websites
* Static sites

## ⚠️ Keep in Mind

Eleventy is primarily a **static site generator**, not a full client-side application framework like React or Vue.

If your project requires highly interactive application-style UI, you may need to add JavaScript or integrate another frontend framework.
