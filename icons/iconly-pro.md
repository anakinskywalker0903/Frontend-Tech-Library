## 📌 What is Iconly Pro?

Iconly Pro is an icon library designed for developers, designers, and product teams.

It provides a large collection of:

* Flat icons
* Animated icons
* 3D icons

The library currently advertises **40,000+ icons**, with thousands of animated and 3D assets.

## ✨ Key Features

* 40,000+ icons
* Flat icon collection
* Animated icons
* 3D icons
* Multiple visual styles
* SVG support
* PNG support
* JSX / TSX formats
* Figma plugin
* Web application
* Customizable icons
* Regular icon updates

## 🎨 Flat Icons

Flat icons are designed around a consistent **24×24 grid** and are available in styles such as:

* Light
* Outline
* Bold
* Two-tone
* Duotone
* Bulk

They can be customized for colors, sizes, and strokes.

## 🎬 Animated Icons

Iconly provides animated icons designed for interactive interfaces.

Features include:

* 60 FPS animations
* Lightweight JSON format
* Multiple categories
* Web usage
* Figma integration

These can be useful for adding subtle feedback and motion to interfaces.

## 🧊 3D Icons

Iconly also provides high-resolution 3D icons with customizable visual properties.

The 3D collection includes options for:

* Lighting
* Materials
* Angle
* Shadows

Useful for:

* Hero sections
* Landing pages
* Marketing websites
* Presentations
* Product interfaces

## ⚠️ Keep in Mind

Iconly Pro is primarily a **design asset library**, rather than a developer-focused icon package.

Check the licensing terms for your specific project before using premium assets commercially.
